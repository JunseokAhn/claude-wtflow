# /wtflow:merge — 기본 브랜치 최신본을 작업 브랜치로

**시작 전에 `${CLAUDE_PLUGIN_ROOT}/references/worktree-discipline.md`(브랜치 이름 규칙·K 모델·note 계층)를 읽는다.**

작업이 길어지면 기본 브랜치가 앞서 나가 충돌이 쌓인다. 그걸 **MR 을 열기 전에** 작업 브랜치 쪽에서
해소해 둔다. `/wtflow:mr` 과 방향이 갈린다:

| | 방향 | 무엇이 바뀌나 |
|---|---|---|
| `/wtflow:merge` | 기본 브랜치 → 현재 브랜치 | **작업 브랜치만** 바뀐다 |
| `/wtflow:mr` | 현재 브랜치 → 기본 브랜치 (요청) | 기본 브랜치는 리뷰를 거쳐서만 바뀐다 |

⚠️ **이 스킬은 기본 브랜치를 건드리지 않는다.** 로컬에서 기본 브랜치에 작업 브랜치를 머지해
push 하면 리뷰를 건너뛴다 — 그 길을 쓰지 않는다.

## 호출

`/wtflow:merge [-b <기본브랜치>]`

| 인자 | 뜻 |
|---|---|
| 생략 | `origin/develop`, 없으면 `origin/main` 을 현재 브랜치로 가져온다 |
| `-b <기본브랜치>` | 가져올 브랜치 명시 |

## 계약

1. **대상은 현재 체크아웃된 브랜치다.** 다른 브랜치를 찾아 나서지 않고, 체크아웃도 옮기지 않는다.
   현재 브랜치가 accumulator(`<prefix>/#<N>-<slug>` 또는 `<prefix>/+<slug>`)가 아니면 보고하고 멈춘다
   — mirror(`-<KKK>`) 위에서 이 작업을 하면 K 경계가 뭉개진다
2. **최신본을 먼저 받아온다.** 로컬 기본 브랜치가 낡아 있을 수 있으니 원격을 직접 쓴다:
   ```
   git fetch origin <기본브랜치>
   git merge --no-ff 'origin/<기본브랜치>'
   ```
   - **기본 브랜치를 체크아웃하지 않는다** — 어디에 나와 있는지 찾을 필요도, 임시 워크트리를 팔
     이유도 없다. 현재 워크트리 안에서 끝난다
   - **메시지를 손대지 않는다.** 기본 메시지 `Merge branch 'origin/<기본브랜치>' into <현재 브랜치>`
     가 그대로 읽히는 이력이 된다. 현재 브랜치는 accumulator 이므로 이름에 K 가 섞이지 않는다
3. **`--no-ff` 고정.** 머지 커밋이 남아야 언제 최신본을 흡수했는지 이력에 보인다
4. **충돌 해소 후 빌드로 검증한다.** 해소가 끝이 아니다:
   컴파일 언어 → `compileJava`/`compileTestJava` 등, TS → `npx tsc --noEmit`, Python → 구문 파싱.
   깨지면 커밋하지 않고 보고한다
5. **push 하지 않는다.** origin 반영·MR 은 `/wtflow:mr` 몫이다
6. **mirror 를 건드리지 않는다.** 이 머지 커밋은 accumulator 에만 쌓인다 — K 에 속한 작업이 아니므로
   mirror 를 새로 만들지 않는다. 다만 accumulator tip 이 앞서므로, 다음 `/wtflow:commit` 이
   최상단 mirror 를 FF 로 끌어올린다

## 충돌 해소 감각

- **import·목 선언 충돌은 대개 "양쪽 다 필요"** 다. 한쪽을 버리기 전에 그 심볼이 정말 안 쓰이는지 본다.
- **한쪽이 다른 쪽의 구형을 들고 오는 경우**가 있다(브랜치를 딴 시점이 달라서). 최신 정의를 살리고
  구형 중복을 버린다 — 어느 쪽이 최신인지는 `git log` 로 확인하고 추측하지 않는다.
- **같은 문제를 다르게 고친 두 브랜치**가 부딪히면 한쪽을 기계적으로 취하지 말고,
  **실제로 검증된 쪽을 기본으로 삼고 다른 쪽의 고유 기여만 흡수**한다. 그 판단 근거를 보고에 적는다.
- 테스트 파일 충돌은 런타임에 영향이 없더라도 **버리지 말고** 양쪽 케이스를 살린다.

## 중단 트리거

- 현재 브랜치가 accumulator 가 아님(mirror·기본 브랜치·detached) → 보고하고 멈춘다
- 워킹트리가 더럽다 → 머지 전에 커밋하거나 치우게 하고 멈춘다(머지가 변경을 빨아들이면 안 된다)
- 충돌 해소에 **제품 결정**이 필요(둘 중 어느 설계를 남길지) → 선택지 제시 후 대기
- 빌드·타입 검사 실패 → 커밋하지 않고 보고
- fetch 실패(원격 접근 불가) → 보고하고 멈춘다. 낡은 로컬 기본 브랜치로 대체하지 않는다
