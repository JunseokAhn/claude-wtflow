# /wtflow:merge — 기본 브랜치 최신본을 작업 브랜치로

**시작 전에 `${CLAUDE_PLUGIN_ROOT}/references/worktree-discipline.md`(브랜치 이름 규칙·Step 모델·note 종류)를 읽는다.**

작업이 길어지면 기본 브랜치가 앞서 나가 충돌이 쌓인다. 그걸 **MR 을 열기 전에** 작업 브랜치 쪽에서
해소해 둔다. `/wtflow:mr` 과 방향이 반대다:

| | 방향 | 무엇이 바뀌나 |
|---|---|---|
| `/wtflow:merge` | 기본 브랜치 → 현재 브랜치 | **작업 브랜치만** 바뀐다 |
| `/wtflow:mr` | 현재 브랜치 → 기본 브랜치 (요청) | 기본 브랜치는 리뷰를 거쳐서만 바뀐다 |

**`/wtflow:mr` 이 MR 을 만들기 전에 이 스킬을 먼저 부른다**(`wtflow:mr` 계약 5). 그래서 보통은
따로 부를 일이 없다 — 직접 부르는 건 MR 과 무관하게 중간에 최신본을 당겨오고 싶을 때다.

⚠️ **머지 규칙은 이 문서에만 둔다.** 기준 브랜치 판정·메시지 형태·충돌 해소·검증은 전부 여기
계약이고, `wtflow:mr` 은 부르기만 한다. 양쪽에 적으면 한쪽만 고쳐져 어긋난다.

⚠️ **이 스킬은 기본 브랜치를 건드리지 않는다.** 로컬에서 기본 브랜치에 작업 브랜치를 머지해
push 하면 리뷰를 건너뛴다 — 그 길을 쓰지 않는다.

## 호출

`/wtflow:merge [-b <기본브랜치>]`

| 인자 | 뜻 |
|---|---|
| 생략 | `develop`, 없으면 `main` 을 현재 브랜치로 가져온다 (원격을 fetch 해 맞춘 뒤 로컬 브랜치를 머지) |
| `-b <기본브랜치>` | 가져올 브랜치 명시 |

## 계약

1. **대상은 현재 체크아웃된 브랜치다.** 다른 브랜치를 찾아 나서지 않고, 체크아웃도 옮기지 않는다.
   현재 브랜치가 accumulator(`<prefix>/#<N>-<slug>` 또는 `<prefix>/+<slug>`)가 아니면 보고하고 멈춘다
   — mirror(`-<KKK>`) 위에서 이 작업을 하면 Step 경계가 뭉개진다
2. **원격을 먼저 받아오고, 로컬 기본 브랜치를 머지한다.**
   ```
   git fetch origin <기본브랜치>                 # origin/<기본브랜치> 만 갱신된다
   git merge --no-ff '<기본브랜치>'              # 로컬 브랜치를 머지 → 'Merge branch ...' 형태
   ```
   - **기본 브랜치를 체크아웃하지 않는다** — 현재 워크트리 안에서 끝난다
   - **메시지를 손대지 않는다.** git 기본값 `Merge branch '<기본브랜치>' into <현재 브랜치>` 가
     그대로 이력이 된다. 현재 브랜치는 accumulator 이므로 이름에 Step 이 섞이지 않는다

   **로컬과 원격이 어긋나 있으면 머지하기 전에 맞춘다** — `git fetch` 는 `origin/<기본브랜치>` 만
   갱신하지 로컬 `<기본브랜치>` 는 건드리지 않는다. 그래서 둘의 관계를 먼저 본다
   (`git rev-list --left-right --count 'origin/<기본브랜치>...<기본브랜치>'`):

   | 관계 | 처리 |
   |---|---|
   | 같음 | 그대로 로컬을 머지한다 |
   | **로컬만 뒤처짐** | `git fetch origin <기본브랜치>:<기본브랜치>` 로 FF 갱신 후 머지 |
   | 그 외(로컬이 앞서거나 갈라짐) | **계약 7 로 간다 — 묻는다** |

   - ⚠️ **FF 갱신이 거부될 수 있다.** 그 브랜치가 다른 워킹트리에 체크아웃돼 있으면 git 이
     `refusing to fetch into branch ... checked out at ...` 로 막는다. 그때는 **`origin/<기본브랜치>`
     를 대신 머지하고, 메시지가 `Merge remote-tracking branch ...` 형태로 남는 이유를 보고에 적는다.**
     `update-ref` 로 우회하지 않는다 — 그 워킹트리의 인덱스가 ref 와 어긋나 없던 변경이 생긴다
   - **결과물은 어느 쪽이든 같다** — tree 와 흡수한 커밋이 동일하고 메시지 문자열만 다르다.
     로컬 형태를 기본으로 두는 건 일반적인 협업 이력과 형태를 맞추기 위해서다
3. **`--no-ff` 고정.** 머지 커밋이 남아야 언제 최신본을 흡수했는지 이력에 보인다
4. **충돌 해소 후 빌드로 검증한다.** 해소가 끝이 아니다:
   컴파일 언어 → `compileJava`/`compileTestJava` 등, TS → `npx tsc --noEmit`, Python → 구문 파싱.
   깨지면 커밋하지 않고 보고한다
5. **push 하지 않는다.** origin 반영·MR 은 `/wtflow:mr` 몫이다
6. **mirror 를 건드리지 않는다.** 이 머지 커밋은 accumulator 에만 쌓인다 — Step 에 속한 작업이 아니므로
   mirror 를 새로 만들지 않는다. 다만 accumulator tip 이 앞서므로, 다음 `/wtflow:commit` 이
   최상단 mirror 를 FF 로 끌어올린다

7. **기준이 갈리면 조용히 고르지 않고 묻는다.** 계약 2 의 관계 판정이 "그 외"(로컬이 앞서거나
   갈라짐)로 떨어지면 **머지 전에 멈추고 `AskUserQuestion` 으로 확인한다.**

   **왜 물어야 하나 — 어느 쪽을 고르냐로 결과가 통째로 달라진다.** 실제로 로컬이 원격보다
   19커밋 앞선 상태에서, 원격 기준으로는 `Already up to date.`(아무 일도 없음)이고 로컬
   기준으로는 19커밋을 흡수했다. 둘 다 정상 종료라 **틀린 쪽을 골라도 티가 나지 않는다.**

   질문에 **반드시 숫자를 함께 낸다** — 어느 쪽이 몇 커밋 앞서는지 없으면 고를 수가 없다:

   | 보기 | 언제 맞나 |
   |---|---|
   | 로컬 `<기본브랜치>` 기준 | 아직 push 안 한 머지가 로컬에만 있다 (다른 작업을 먼저 흡수한 경우) |
   | `origin/<기본브랜치>` 기준 | 로컬 브랜치가 실험·실수로 앞서 있어 버릴 것이다 |
   | 멈춤 | 왜 갈렸는지 모르겠다 — 사람이 먼저 확인한다 |

   - **`(추천)` 을 붙이지 않는다.** 어느 쪽이 맞는지는 사용자만 아는 로컬 사정이고, 추천을 달면
     그 사정을 확인하지 않고 통과시키게 된다
   - `wtflow:mr` 이 이 스킬을 부른 경우에도 **똑같이 멈추고 묻는다.** MR 을 만드는 흐름이라고
     해서 임의로 고르면, 잘못 고른 기준이 그대로 리뷰에 올라간다
   - 로컬이 **뒤처지기만** 한 경우는 묻지 않는다 — 계약 2 대로 FF 로 맞추면 그만이라 고를 게 없다

## 충돌 해소 감각

- **import·목 선언 충돌은 대개 "양쪽 다 필요"** 다. 한쪽을 버리기 전에 그 심볼이 정말 안 쓰이는지 본다.
- **한쪽이 다른 쪽의 구형을 들고 오는 경우**가 있다(브랜치를 딴 시점이 달라서). 최신 정의를 살리고
  구형 중복을 버린다 — 어느 쪽이 최신인지는 `git log` 로 확인하고 추측하지 않는다.
- **같은 문제를 다르게 고친 두 브랜치**가 부딪히면 한쪽을 기계적으로 취하지 말고,
  **실제로 검증된 쪽을 기본으로 삼고 다른 쪽의 고유 기여만 흡수**한다. 그 판단 근거를 보고에 적는다.
- 테스트 파일 충돌은 런타임에 영향이 없더라도 **버리지 말고** 양쪽 케이스를 살린다.

## 중단 트리거

- 현재 브랜치가 accumulator 가 아님(mirror·기본 브랜치·detached) → 보고하고 멈춘다
- 워킹트리가 더럽다 → 머지 전에 커밋하거나 치우게 하고 멈춘다(머지가 변경을 빨아들이면 안 된다)
- 충돌 해소에 **제품 결정**이 필요(둘 중 어느 설계를 남길지) → 선택지 제시 후 대기
- 로컬 기본 브랜치와 원격이 갈림(로컬이 앞서거나 갈라짐) → **머지 전에** 계약 7 로 묻고 대기
- 빌드·타입 검사 실패 → 커밋하지 않고 보고
- fetch 실패(원격 접근 불가) → 보고하고 멈춘다. **낡았을 수 있는 로컬 기본 브랜치를 그대로 머지하지 않는다** — 원격을 못 봤으면 뒤처졌는지 알 수 없다
