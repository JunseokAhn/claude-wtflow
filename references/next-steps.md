# 작업을 마친 뒤 다음 단계 안내

작업을 다 끝낸 자리에서 내는 **MR 올리기 · MR 없이 끝내기** 안내 블록. 블록을 여기 한 벌만 둔다.
**`auto`(순회 끝)·`merge`(보고)·`commit`(마지막 작업 항목을 닫은 뒤)이 이 블록을 낼 때 읽는다.**
어느 자리에서 내는지와 언제 안 내는지는 각 스킬이 정한다 — 여기는 블록과 공통 규칙만 갖는다.

## 블록

한 줄에 명령 하나. 문장은 응답 언어로 옮겨 쓴다(`response-language.md` 의 `## 고정 문장도 옮겨 쓴다`):

```
다음 단계 — MR 올리기:
  /wtflow:mr                    MR 만 올림
  /wtflow:mr --clean            MR 을 올린 뒤 브랜치 정리
  /wtflow:mr --clean -f         MR 을 올린 뒤 브랜치 정리(미병합본이 있어도 전부)

MR 없이 끝내기:
  /wtflow:merge --local         로컬 develop 에 합친 뒤 브랜치 정리
  /wtflow:merge --local --close 로컬 develop 에 합치고 정리한 뒤 이슈 닫기
```

## 공통 규칙

- **이슈 없는 작업이면 `--close` 줄을 뺀다** — 닫을 이슈가 없다
- **안내만 한다** — 이 블록을 낸 스킬이 `/wtflow:mr`·`/wtflow:merge` 를 대신 부르지 않는다.
  `--push` 를 받았어도 같다. MR·머지는 사용자가 고른다
- 정리 옵션(`--clean`·`--local`)까지 같이 적는다 — 빼면 사용자가 스킬 문서를 열어 찾아야 한다
